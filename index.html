AI 影音工坊

純瀏覽器版 · 打開網頁即可用，無需下載安裝
這個版本完全在你的瀏覽器裡運算，沒有伺服器上傳你的內容。合成時是「即時錄製」（跟影片長度差不多久），過程中請讓這個分頁保持在前景，切到背景分頁會讓錄製卡頓或畫面全黑。建議使用 Chrome 或 Edge。

02選片 等待腳本
🔑 Pexels API 金鑰

到 pexels.com/api 免費申請。金鑰只存在你的瀏覽器裡，直接從瀏覽器打給 Pexels，不會經過任何伺服器。

📁 我的影片庫（上傳自己的影片素材）

上傳的影片只存在你的瀏覽器裡（IndexedDB），不會上傳到任何伺服器；建議單支在數十 MB 內，太大的檔案可能讓瀏覽器變慢或占用大量空間。上傳後可在下方各段落按「📁 我的影片庫」套用。

03配音 等待腳本
🔧 語音服務代理網址

瀏覽器沒辦法直接呼叫線上配音服務（會被安全限制擋掉），需要一個極輕量的代理網址幫忙轉發。這個網址只存在你的瀏覽器。

🚀 想擁有自己專屬的配音服務？（免費，約 5 分鐘，不需信用卡）

作者提供的預設代理是大家共用的，流量大時可能會變慢或暫時用不了。花幾分鐘申請一個屬於你自己的 Cloudflare 帳號（免費方案每天 10 萬次請求，個人使用綽綽有餘），就能有一個只有你自己在用、永遠不會被別人排擠的配音服務：

  1. 到 dash.cloudflare.com/sign-up 免費註冊、登入
  2. 左側選單找「Workers & Pages」→「Create」→「Create Worker」，取個名字後按「Deploy」（會先出現一個預設的 Hello World 版本，沒關係）
  3. 進到剛建立好的 Worker 頁面，按右上角「Edit code」，把下面這段程式碼整段複製、貼上蓋掉原本內容，再按右上角「Deploy」
  4. 部署完成會拿到一個 https://你的名字.你的帳號.workers.dev 網址，複製起來，貼回上面「🔧 語音服務代理網址」欄位並按「儲存」

這段程式碼跟這個網站用的預設代理完全相同（本專案 GitHub repo 裡的 worker.js），只會把你的配音文字轉送給線上語音服務、不會儲存任何內容。

04合成 等待素材
🎵 配樂（選用，不上傳也能合成影片）

上傳一首音樂當背景配樂，合成時會自動循環播放並與配音混音（結尾 2 秒淡出）。只存在你的瀏覽器裡，不會上傳到任何伺服器；不上傳也完全可以正常合成影片。請確保自己擁有該音樂的合法使用權利。建議檔案在數十 MB 內。

⚠ 語音採線上制式聲音，非真人聲音克隆。合成完全在瀏覽器內完成，輸出格式依瀏覽器支援自動選擇（優先 .mp4，不支援時退回 .webm）。

⚠ 使用限制：影片素材來自 Pexels，依 Pexels 授權條款可免費使用（禁止原封不動轉售素材本身）；若改用「我的影片庫」上傳自己的影片、或上傳配樂音樂，請確保自己擁有該素材的合法使用權利，本工具不負責使用者上傳內容的授權爭議。

⚠ 本工具僅供個人教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用。
