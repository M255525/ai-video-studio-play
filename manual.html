🎬 AI 影音工坊（純瀏覽器版）操作手冊

用 Pexels 免費影庫的畫面配上線上語音配音與字幕，一站合成短影片。整個運算過程都在你的瀏覽器裡完成，沒有任何伺服器儲存你的內容；打開網頁即可用，不需要下載安裝或申請帳號（唯一例外是 Pexels 金鑰，免費申請）。

技術限制：合成是「即時錄製」
這個版本沒有後端伺服器幫忙用 ffmpeg 快速合成，改用瀏覽器內建的 MediaRecorder 邊播邊錄，所以合成所需時間跟影片長度差不多（例如影片 30 秒，合成也要花大約 30 秒）。過程中請讓分頁保持在前景，切到背景分頁或最小化視窗會讓瀏覽器降低更新頻率，導致畫面卡頓甚至全黑。建議使用 Chrome 或 Edge（Safari 對這裡用到的瀏覽器功能支援較不穩定）。
配音為什麼需要一個額外的網址？
瀏覽器基於安全設計，不允許網頁的 JavaScript 程式碼偽造連線來源（Origin），而線上語音合成服務會檢查這個來源，所以網頁沒辦法直接連上去要求配音。解法是透過一個極輕量的「代理」（跑在 Cloudflare 免費方案上，不是傳統意義的伺服器，也不會儲存任何內容），只負責把配音請求轉發過去、把結果原封不動送回來。這是唯一「不是純瀏覽器完成」的一步，其餘搜尋、下載、合成、字幕、浮水印都在你的瀏覽器裡跑。

🚀 快速開始

  1. 直接打開這個網頁（GitHub Pages 網址或本機檔案皆可）。
  2. 在「01 腳本」輸入文字（一行一段，格式：字幕文字 | 英文搜尋關鍵字），選好聲音與語速，或直接按內建範例，按「建立段落」。
  3. 「02 選片」：展開 🔑 填入 Pexels 金鑰（免費申請，見下方），每段按「搜尋影片」挑一部喜歡的畫面；也可以按「📁 我的影片庫」改用自己上傳的影片素材（見下方「📁 使用自己上傳的影片」）。
  4. 「03 配音」：展開 🔧 確認「語音服務代理網址」已填好（作者已預先填入預設網址；若失效可自行部署一份，見下方），按「生成全部配音」。
  5. 「04 合成」：展開「🎵 配樂」可選擇上傳一首背景音樂（非必要，見下方「🎵 使用配樂」），按「合成影片」，保持分頁在前景等待錄製完成（約等於影片長度），完成後可預覽、下載（優先 .mp4，瀏覽器不支援時自動退回 .webm）或直接分享。

🧰 事前準備：申請 Pexels API 金鑰（免費）

到 pexels.com/api 註冊即可立即取得金鑰，填入「02 選片」的 🔑 金鑰欄位。金鑰只存在你的瀏覽器裡，搜尋/下載影片時直接從你的瀏覽器打給 Pexels，不會經過任何中間伺服器。

📋 四個階段

階段做什麼
01 腳本一行一段輸入字幕文字與搜尋關鍵字，並選擇配音聲音與語速。台詞不變時，重建段落會保留已選的影片。
02 選片選擇畫面方向（橫式/直式）；每段可搜尋 Pexels、按 💡 從常用關鍵字挑選，或按 📁 改用自己上傳到「我的影片庫」的素材。Pexels 搜尋直接在瀏覽器裡呼叫，不經過任何伺服器；上傳的影片也只存在你自己的瀏覽器裡。
03 配音按「生成全部配音」，透過語音服務代理取得每段口白（需要網路連線）。
04 合成可選擇上傳配樂（見下方「🎵 使用配樂」），可勾選把字幕燒進畫面。瀏覽器即時播放＋錄製，輸出 1920×1080（橫式）或 1080×1920（直式）的影片（瀏覽器支援時直接輸出 .mp4，否則退回 .webm），右下角固定燒錄「AI Video Studio」浮水印；完成後可下載，或在支援的裝置上直接按「分享影片」傳到其他 App。

📁 使用自己上傳的影片

如果不想用 Pexels 免費影庫、想放自己拍的畫面，可以在「02 選片」上方展開「📁 我的影片庫」，用檔案選取器一次上傳一支或多支影片（accept="video/*"，常見的 .mp4／.mov／.webm 檔案瀏覽器多半都能讀）。上傳完成後，每個段落的「📁 我的影片庫」按鈕會開啟一個縮圖選單，點一下就套用到該段。

存在哪裡、跟 Pexels 素材有什麼不一樣？
上傳的影片實際位元組存在瀏覽器的 IndexedDB 裡，不會上傳到任何伺服器，也會在重新整理頁面、關掉分頁後繼續保留（這點跟腳本/選片紀錄一樣持久，但跟「配音音檔、合成結果重新整理就會消失」不同——上傳的影片是目前唯一被真正持久保存的素材）。清除瀏覽器資料（清除瀏覽紀錄/網站資料）會把它們一併清掉；也可以在「我的影片庫」縮圖上按 🗑 手動刪除。刪除後，原本套用該影片的段落合成時會提示需要重新選片。

建議單支影片維持在數十 MB 內；檔案太大或太多支會占用較多瀏覽器儲存空間，也可能讓縮圖產生、合成錄製變慢。

🎵 使用配樂（背景音樂）

想幫影片加背景音樂，可以在「04 合成」上方展開「🎵 配樂」，上傳一首音樂檔（accept="audio/*"，常見的 .mp3／.wav／.m4a 瀏覽器多半都能讀）。合成時這首音樂會自動從頭循環播放到全片結束，並在結尾 2 秒漸漸淡出，跟配音一起混音錄進輸出影片；旁邊的音量滑桿可以調整配樂大小聲（配音本身音量不受影響）。不上傳配樂完全不影響合成，這是選用功能。

存在哪裡？
上傳的配樂只存在你目前這個分頁的記憶體裡，不會上傳到任何伺服器，但也不會持久保存——重新整理頁面後要重新上傳一次（跟配音音檔、合成結果一樣，不像「📁 我的影片庫」的影片素材會存進 IndexedDB 持久保留）。

請確保自己擁有該音樂的合法使用權利（自己創作、有授權、或無版權/創用CC 音樂）；建議檔案在數十 MB 內。

💾 資料存在哪裡

腳本、關鍵字、已選的影片連結存在瀏覽器 localStorage，關掉分頁不會消失；自己上傳的影片存在 IndexedDB，同樣會持久保留（見上方「📁 使用自己上傳的影片」）。配音音檔、上傳的配樂、合成結果都不會被保留（重新整理頁面後配音要重新生成一次、配樂要重新上傳、合成也要重新跑一次）——這是純瀏覽器架構的取捨，換來的是完全不需要任何後端儲存空間。

🚀 申請你自己專屬的配音服務（免費，約 5 分鐘）

作者提供的預設代理是大家共用的，流量大時可能會變慢。「03 配音」下方展開「🚀 想擁有自己專屬的配音服務？」就有完整步驟與一鍵複製的程式碼，不需要安裝任何軟體或用終端機：

  1. 免費申請 Cloudflare 帳號（不需信用卡）
  2. 「Workers & Pages」→「Create」→「Create Worker」，取名後「Deploy」
  3. 進到該 Worker「Edit code」，貼上頁面裡按一下就能複製的程式碼，再「Deploy」
  4. 把拿到的 https://xxx.workers.dev 網址貼回「🔧 語音服務代理網址」欄位

如果你比較習慣用終端機，也可以用 npx wrangler deploy（需先 npx wrangler login）部署本專案 repo 裡的 worker.js，效果完全相同。

❓ 常見問題

配音失敗，顯示「尚未設定語音服務代理網址」？
展開「03 配音」下方的「🔧 語音服務代理網址」，確認網址存在且正確；若持續失敗可能是該代理服務暫時額度用盡或離線。

搜尋失敗（401 / 未設定金鑰）？
確認已在「02 選片」填入 Pexels 金鑰；金鑰錯誤請重新複製貼上。

合成到一半畫面卡住或變黑？
合成期間分頁被切到背景（例如切換視窗、最小化）會讓瀏覽器降頻導致這個現象。請重新合成一次，過程中保持分頁在最前面、不要切換。

下載的影片副檔名是 .webm 不是 .mp4？
輸出格式是由瀏覽器內建 MediaRecorder 自動偵測決定：優先嘗試直接輸出 .mp4（較新版本的 Chrome / Edge 通常支援），不支援時才退回 .webm。「04 合成」按鈕上方會先顯示目前這個瀏覽器會輸出哪種格式。若拿到 .webm 但需要 .mp4，可用任何免費線上轉檔工具或 ffmpeg -i in.webm -c:v libx264 out.mp4 轉換，或換一個較新版本的 Chrome / Edge 再合成一次。

「分享影片」按鈕沒反應，或提示不支援分享？
這個功能用的是瀏覽器原生的「分享檔案」能力（Web Share API），目前主要在手機版 Chrome / Edge，以及部分較新的桌面版瀏覽器支援；不支援時會顯示提示文字，請改按左邊「下載影片」，再從檔案總管、相簿或通訊軟體手動分享下載好的檔案。

上傳的影片找不到、合成時報錯「找不到這支已上傳的影片」？
代表這支影片已經從「我的影片庫」被刪除（或是在另一個瀏覽器/無痕視窗開的頁面，IndexedDB 資料不共通）。回到「02 選片」該段落重新按「📁 我的影片庫」選一次，或重新上傳一次那支影片。

使用限制
影片素材來自 Pexels，依 Pexels 授權條款可免費使用（禁止原封不動轉售素材本身）；若改用「📁 我的影片庫」上傳自己的影片，請確保自己擁有該素材的合法使用權利。
配音為線上制式聲音，非真人聲音克隆，可自由使用生成結果。
